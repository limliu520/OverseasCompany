版本目的

本版交付：本地拖入素材节点、当前画布生成素材库（含搜/排/预览/定位/zip 等）、视频超分、节点 @（含视频@文本）、右键补齐、引用小块统一、文本大模型、主体基础能力、生成中循环 loading。

QM-2101

P0-1 本地拖入成节点

功能逻辑

用户把本地文件拖进画布（或点左侧上传，规则对齐）。按扩展名落成节点：图片→图片节点，视频→视频节点，音频→音频节点，.md→文本节点。拖入的图/视/音为纯素材：可预览、可被 @，节点下方没有大模型生成条。

业务规则

  • 支持扩展名：常见图片（png/jpg/jpeg/webp/gif）、视频（mp4/mov/webm）、音频（mp3/wav/m4a/aac）、Markdown（.md）。
  • 其它扩展名：不落节点；Toast「不支持的文件类型：{ext}（仅图/视/音/md）」。
  • 本地图/视/音：无底部提示词与生成按钮；AI 生成类节点才有生成条。
  • 本地视频：悬停即预览播，▶ 隐藏，左下显示当前/总时长，右下静音·放大，右上更换+下载。
  • AI 生成视频：须点击 ▶ 才播放；悬停只出控件与清晰度，不自动播。
  • 图片：无播放按钮；悬停右上「下载」「替换素材」。
  • 音频：无修剪；右上更换+下载并排；左下时长，右下播放。
  • .md 拖入：正文进文本节点；脚注「来源：.md 拖入」；@ 时类型仍为「文本」。
  • 一次拖入多个文件：只导入第一个，并按上面的类型规则落成一个节点；其余文件不落节点。Toast「一次仅导入第一个文件，其余未导入」。
  • 系统剪贴板粘贴（不是画布里「复制节点」后再粘贴）：画布获得粘贴时，剪贴板里的图片、视频、音频、.md、纯文本，与拖入 / 左侧上传同一套类型规则。纯文本落成文本节点，正文为剪贴板文字。多文件同样只导入第一个。画布内复制的节点仍走右键「粘贴」（见 P1-1），不按文件导入。
  • 自动命名（用户改名之前）：系统自己起名的节点用「类型名 + 空格 + 序号」，同类型按已有数量递增。视频为「视频 1」「视频 2」「视频 3」，图片 / 音频 / 文本 / 主体同理。拖入或粘贴且文件自带文件名时，用文件名，不套这套序号。新建画布同理，默认名「自定义画布 1」「自定义画布 2」「自定义画布 3」，不重复成同一个「自定义画布」。

页面交互

  • 拖入命中画布空白或节点层上方可落点区域即创建节点（Demo 落在试验区示意）。
  • 左侧栏上传与拖入同一套类型规则。
  • 状态矩阵：本地视频悬停→预览播；生成视频默认▶→点击播放。

异常

  • 文件损坏或读失败：不落节点；Toast「文件无法读取，请重试」。
  • 同名文件：允许落多个节点，名称用文件名，不自动去重合并。
  • 拖入过程中离开窗口：取消本次落点，不创建半成品节点。
  • 多文件时只处理第一个；剪贴板为空、或不是图/视/音/md/纯文本：不落节点，Toast「剪贴板没有可导入的内容」。

数据流转

本地文件 → 前端解析类型 → 创建对应节点并写入媒体/正文引用 → 可被下游 @ 与连线；不进入「当前画布生成素材」列表。

QM-2102

P0-2 当前画布生成素材

功能逻辑

左侧栏提供「当前画布生成素材」入口，弹窗列出本画布 AI 已成功生成的图/视/音成品（不含本地拖入、不含生成中与失败）。支持类型 Tab、搜索、时间排序、勾选、预览、定位、下载（单文件/多选 zip）。本期不支持删除（底栏无删除/批量删除）。

弹窗内勾选存在四种相关态：列表空、未选（N=0）、单选（N=1）、多选（N≥2）；底栏按钮文案与点击结果按态区分，见下方状态矩阵。

业务规则

  • 范围：仅当前画布、ai 生成且已有成品；本地拖入永不进列表；生成中/失败不进列表。
  • Tab：全部 / 图片 / 视频 / 音频；切换 Tab 后重新计算「当前筛选结果」，已勾选但不在新结果里的项自动取消勾选。
  • 搜索：匹配节点名或提示词摘要（不区分大小写）；清空搜索即恢复当前 Tab 下全量。
  • 排序：生成时间新→旧 / 旧→新；仅改展示顺序，不改变勾选集合。
  • 勾选：单击卡片切换勾选；已勾选卡片高亮 + 左上角勾选态。勾选数 N = 当前筛选结果中已勾选的卡片数。
  • 底栏文案「已选择 N 个」：随勾选实时刷新；列表空时显示「已选择 0 个」。
  • 全选当前：把当前筛选结果（当前 Tab + 搜索后的列表）全部勾选只勾选当前页（每页最多 20 条）；若当前页空则无操作、勾选仍为 0。
  • 取消全选：清空全部勾选，N→0；不关闭弹窗、不改 Tab/搜索/排序。
  • 下载：单选（N=1）按钮文案「下载」，直接下载与节点下载同一文件；多选（N≥2）文案「批量下载」，打包 zip；未选（N=0）文案仍为「下载」，点击不下载（见异常）。本期不提供删除。
  • 侧栏入口与主体库都是文件夹类图标，悬停只显示两个字，避免和资产库、主体库混在一起。本画布 AI 生成素材的悬停文案定为「成片」（成片 = 本画布已生成的成品，不是资产库里的「素材」）。
  • 列表分页：按当前 Tab + 搜索 + 排序之后的结果分页，每页 20 条。底栏提供「上一页」「下一页」，不提供输入页码跳转。同时展示「第 {当前} / {总页数} 页」。只有 1 页时上一页、下一页可点但 Toast「已经是第一页」或「已经是最后一页」，不翻页。筛选或搜索变化后回到第 1 页。
  • 一次下载最多 20 个（与一页条数相同）。N>20 时不下载、不打包其中一部分，Toast「一次最多下载 20 个」。下载开始后底栏进入「下载中 {已完成}/{总数}」，完成前不重复发起；全部成功后 Toast「下载完成」并回到可再次下载；任一项失败则 Toast「下载失败，请重试」，已完成的不回滚，未完成的停在失败项。
  • 预览：双击卡片（或点预览入口）在弹窗内放大预览；不关闭弹窗、不改勾选。未勾选也可预览当前卡片。
  • 定位到画布（已定）：本期仅支持单个节点定位。按钮文案恒为「定位到画布」，不随 N 变成「批量定位」。遵循规范「不支持则不半执行」——多选时不定位第一项充数。
    • 未选（N=0）：可点击；不定位；Toast「请先选择一项以定位」；弹窗不关；勾选不变；画布不变。
    • 单选（N=1）：关闭弹窗；画布选中该节点；节点滚入视野；Toast「已定位到画布节点」。
    • 多选（N≥2）：可点击；不执行定位（不关弹窗、不改画布、不改勾选）；Toast「仅支持单个节点定位」。
  • 列表空态文案：本画布还没有生成内容。去画布上生成后再来。（并说明本地拖入不会出现）。搜索无结果另见异常。

页面交互

  • 入口：左侧栏与文本/图/视/音/主体/库/上传并列；点击打开弹窗，默认 Tab=全部、排序=新→旧、搜索空、勾选清空（N=0）。
  • 关闭：点「关闭」或遮罩（若实现）关闭弹窗；不清除画布数据；再次打开按上条默认重置筛选与勾选。
  • 以下操作按勾选态区分结果（按钮是否禁用见矩阵；本期底栏按钮均保持可点，未满足条件时用 Toast 拦截，避免灰态不易发现）：
勾选态底栏「已选择」「定位到画布」「下载」按钮「全选当前」「取消全选」
列表空（当前筛选 0 条） 已选择 0 个 可点 → Toast「请先选择一项以定位」；弹窗不关 文案「下载」；可点 → Toast「请先选择要下载的项」 可点 → 无变化（仍 0） 可点 → 无变化（仍 0）
未选（有卡片，N=0） 已选择 0 个 可点 → Toast「请先选择一项以定位」；弹窗不关；画布不变 文案「下载」；可点 → Toast「请先选择要下载的项」；不触发下载 可点 → 勾选当前筛选全部；N=筛选条数；卡片全高亮 可点 → 保持 N=0
单选（N=1） 已选择 1 个 可点 → 关弹窗；画布选中该节点并滚入视野；Toast「已定位到画布节点」 文案「下载」；可点 → 单文件下载（与节点下载同一文件） 可点 → 升为多选（全选当前筛选） 可点 → N=0，卡片取消高亮
多选（N≥2） 已选择 N 个 可点 → 不定位；Toast「仅支持单个节点定位」；弹窗不关；勾选与画布不变 文案「批量下载」；可点 → 若 N≤20 则打包 zip 下载 N 项；若 N>20 则不下载，Toast「一次最多下载 20 个」 可点 → 仍全选当前筛选（幂等） 可点 → N=0

预览（双击卡片）：四种勾选态下行为相同——弹窗内放大预览，不关弹窗、不改 N。切换 Tab / 搜索 / 排序：不关闭弹窗；Tab/搜索会重算筛选并剔除不在结果内的勾选；排序只改展示顺序。

异常

  • 未选点下载：触发条件 N=0（含列表空）→ 不发起下载 → Toast「请先选择要下载的项」→ 可继续勾选后重试。
  • 未选点定位：触发条件 N=0 → 不关弹窗、不改画布 → Toast「请先选择一项以定位」→ 可继续勾选后重试。
  • 多选点定位：触发条件 N≥2 → 不执行定位（不关弹窗、不改画布、不改勾选）→ Toast「仅支持单个节点定位」→ 用户取消多余勾选至 N=1 后可重试。
  • 搜索无结果：网格空 + 文案「无匹配结果」；底栏仍「已选择 0 个」；不展示假下载项；下载/定位同未选拦截。
  • 下载失败：Toast「下载失败，请重试」；勾选与弹窗保持；成品不删除（本期本无删除）。进行中的批量下载停在失败项，状态从「下载中」回到可再次下载。
  • 勾选超过 20 个再点下载：不进入下载中，Toast「一次最多下载 20 个」。
  • 单选定位时目标节点已不在画布：关弹窗后 Toast「节点已不存在」；列表下次打开刷新移除该项。
  • 列表缓存含已删节点：打开/刷新列表时移除；不出现在勾选与下载包中。

数据流转

画布节点生成成功 → 写入列表索引 → 用户筛选/勾选（维护选中 ID 集合）→ 下载：N=1 单文件 / N≥2 zip；定位：仅当 N=1 时关弹窗并将画布 selectedId 设为该项并滚入视野；N≠1 时不写画布选中。

QM-2103

P0-3 视频超分

功能逻辑

视频可先以较低清晰度生成，再对成片做超分得到更高清晰度版本，不重跑文生/图生视频。多清晰度留在同一节点，媒体区左下角 pills 切换预览。入口有两处：节点「超分」；以及点「下载」时弹出清晰度/超分选择（选更高清则先超分再下，并在该节点写入新清晰度 pills）。

业务规则

  • 仅AI 生成且有成片的视频节点支持超分与「下载时选超分」；图片/音频无超分；本地拖入视频点下载直接下原文件，不出现超分选项。
  • 主入口：有成片视频节点上「超分」——对当前成片发起超分，结果写入同节点 versions，左下出现/更新 pills。
  • 下载入口（本期必做）：有成片的 AI 视频点「下载」必须先弹出选择面板，不可直接静默下载当前预览清晰度。面板内列出：
    • 已有清晰度：文案形如「下载 {清晰度}」（如「下载 720P」）；选中确认后立刻下载该文件，不发起超分、不改 pills。
    • 可超分到的更高清：文案形如「超分并下载 {清晰度}」（如「超分并下载 1080P」）；选中确认后先走超分任务，成功后再下载目标清晰度文件。不展示点数/不计费。展示与其它生成相同的统一货币消耗（文案形态与现网扣费一致，如「约 n 货币」）；本版不写死单价数字。
  • 选超分并下载成功后的节点变化（已定）：超分产物写入同一视频节点的 versions[]；媒体区左下默认增加对应清晰度切换 pills（与点节点「超分」成功后一致）；当前预览清晰度切到刚超分出的目标清晰度；不新建节点、不断线、不丢提示词。
  • 结果展示：同节点多版本；左下 pills 切换预览；当前项高亮；切换仅改预览，不触发下载。
  • 超分中（节点「超分」或「超分并下载」共用）：OPT-2 循环 loading（已等待 + 通常约 x 分钟；无取消）。下载选择面板在提交超分后关闭；任务进行中节点「下载」「超分」禁用或点击 Toast「超分进行中，请稍候」。
  • 失败：保留原清晰度；不写入新 pill；不下载；Toast「超分失败，请重试」；可再从「超分」或「下载」重试。
  • 空视频：无「超分」；「下载」禁用。
  • 超分不计费（已定）：超分是服务端/客户端的代码规则处理（对已有成片做清晰度提升），不是 AI 重新生成，不消耗点数/额度。面板与节点「超分」均不展示「约 n 点」；与文生/图生视频的积分扣费文案严格区分。不存在「超分点数不足」拦截。超分有成本，扣的是现在全站同一套货币，不是单独一种点数。本版只要求界面让用户看到「这次超分会消耗统一货币」；具体单价、档位、扣费公式不写在本 PRD，后台配置规则另开文档统一。货币不足时不发起超分，Toast「货币不足，无法超分」，成片与清晰度保持原样。
  • 已有目标清晰度时：面板只展示「下载 {清晰度}」，不再展示「超分并下载」同档，避免重复超分。

页面交互

  • 悬停/选中有成片 AI 视频时显示「超分」「下载」等。
  • 点「下载」→ 打开「选择下载清晰度」面板（遮罩；Esc / 点取消 / 点遮罩关闭，关闭后不下载、不超分）。
  • 面板默认选中：当前 previewRes 对应的「下载 {清晰度}」项；用户可改选其他已有档或「超分并下载」档。
  • 点确认：
    • 选已有档 → 立即开始下载该文件 → 关面板 → Toast「开始下载 {清晰度}」。
    • 选超分档 → 关面板 → 节点进入超分中 → 成功：写入 pill、previewRes=目标档、开始下载该档 → Toast「超分完成，开始下载 {清晰度}」；失败见异常。
  • 清晰度 pills 在画面左下；有播放时长时叠在时长上方。
  • 节点「超分」与「下载→超分并下载」成功后的 pills 表现一致，不维护两套 UI。
节点状态点「下载」选「下载已有」选「超分并下载」左下 pills
空视频 / 无成片 按钮禁用，无面板 — — 无
仅有 720P 出面板：下载 720P；超分并下载 1080P（示意档位以产品配置为准） 直接下 720P；pills 不变 超分 → 成功后 pills 出现 720P + 1080P，预览切 1080P，再下 1080P 成功前可仅 720P 或暂无多档；成功后至少两档
已有 720P + 1080P 出面板：下载 720P、下载 1080P（无重复超分项） 直接下所选档；pills 不变 — 保持已有 pills

异常

  • 无成片点超分：不可用或 Toast「无成片，不能超分」。
  • 无成片点下载：按钮禁用；若仍触发 → Toast「无成片，无法下载」。
  • 下载面板打开后点取消/Esc/遮罩：不下载、不超分、勾选态不适用（面板选项复位）。
  • 超分失败：恢复可操作；原清晰度仍可预览/下载；不新增 pill；Toast「超分失败，请重试」。（超分不计费，无点数不足类异常。）货币不足见上条，与任务失败分开：不足则未开始；失败则已开始后未得到新清晰度。
  • 超分成功但下载失败：pill 已写入可切换；Toast「下载失败，请重试」；用户可再点下载选已有档重试（不支持则不半执行：不假装已下载）。
  • 重复点击超分 / 超分中再点下载：忽略或 Toast「超分进行中，请稍候」，防双任务。

P0-4 节点 @ 与连线

功能逻辑

在可生成节点的提示词区通过 @ 或 + 添加参考。选中后：输入框出现高亮「@名称」，上方出现统一引用小块，并通过校验后连线。生成框贴在当前选中节点下方。

业务规则

@ 允许类型矩阵（当前节点类型 → 可引用的参考类型）：

当前节点可 @ 的参考类型不可 @
视频主体、图片、视频、音频、文本—
图片主体、图片视频、音频、文本
音频主体、图片、音频视频、文本
文本图片、视频、音频、文本主体

@ 与连线四规则：

  • 规则 1：@ 成功 → 自动连线（from 参考 → to 当前节点）。
  • 规则 2：只拉线 → 不自动写入 @ / 小块。
  • 规则 3：删 @ / 引用小块 → 连线保留。
  • 规则 4：删连线 → 必须同时去掉对应 @ 与小块。
  • 本地素材可被 @。
  • 首尾帧模式不支持用 @ 填帧槽。
  • 本期无 Agent @。
  • 无主图主体：仍出现在 @ 候选列表中（可标注「无主图」），保持可点；点击后不引用、不连线，Toast「请先添加主体图片」。禁止静默灰掉不可点（用户不知道原因）。
  • 文本节点选主体：主体仍可出现在列表中并保持可点；点击后不引用，Toast「文本节点不能引用主体」。
  • 重复引用同一节点：该项可点；点击后不重复添加，Toast「已引用」。

页面交互

  • 入口要分开（对齐千幕，勿混）：
    • 输入「@」或点「@ 参考」→ 打开画布节点参考菜单（按类型分组列出可 @ 候选）。
    • 点引用区「+」→ 先打开来源菜单（与千幕一致）：「本地添加」「从资产库选择」「从画布选择」；不要一点 + 就直接弹出 @ 候选列表。
  • 来源菜单三项：
    • 本地添加：选本地文件作为参考（规则同拖入类型校验）。
    • 从资产库选择：打开资产库选素材作参考。
    • 从画布选择：再进入画布节点参考菜单（与点「@ 参考」同一套候选与矩阵）。
  • 从画布选中候选后：插入不可拆字的 mention 芯片「@名称」，上方出现引用小块，并按规则 1 连线。
  • 点小块 × 同时移除输入框对应 mention；连线仍在（规则 3）。

异常

  • 矩阵外非法类型：不出现在菜单（类型根本不允许，不是「条件暂不满足」）。
  • 条件不满足但仍列出的项（无主图主体、文本点主体、已引用等）：可点 → Toast 完整文案 → 零副作用；见规范「可点 + Toast」。
  • 候选节点被删：菜单刷新不含该项；已引用悬停提示「节点内容为空」或「节点已不存在」。
  • 空内容节点仍可引用，但悬停提示「节点内容为空」。

数据流转

选择参考 → 写 refs[] + mention → edges 增加 from→to → 生成请求携带参考 ID。

P1-1 节点右键与空白右键

功能逻辑

补齐节点右键与空白画布右键。复制=剪贴板；复制副本=画布立即多一份。空白「新建节点 ›」子菜单选类型后才落节点。本期不做「应用全部历史」。

业务规则

  • 通用（多数节点都有）：重命名、复制、复制副本、粘贴、下载、撤销/重做、锁定、定位、删除。无素材时点下载 → Toast「无素材可下载」（或文案可见的「下载（无素材）」）；无历史时撤销/重做同理提示或带原因禁用。
  • 三种「复制」别混（必须写清）：
    • 「复制」：把节点数据放进剪贴板；画布上不会立刻多节点；之后在空白处「粘贴」才落一个新节点。
    • 「复制副本」：在画布上立刻再放一份同配置节点（坐标错开），不依赖粘贴。
    • 「复制为图片」：仅图片节点有；把当前画面当成系统图片拷到剪贴板（可粘到微信/PS 等），不是复制节点，也不会在画布多节点。
  • 「保存到主体库」是什么：在账号主体库里创建（或更新）一条主体资产——把当前可用的角色/物体画面沉淀进去（不是普通素材库）。成功后 Toast「已保存到主体库」。
    • 画布上不会因此自动新建一个主体节点；当前图片/视频/主体节点保持原样。
    • 若要在画布上出现主体节点：走左侧「主体」新建，或主体卡「导入主体」从主体库选入（另一步）。
    • 对主体节点：把本卡身份写入账号库（本卡仍留在画布）。对图片：用当前图片在库里新建一条主体（主图=该图）。对有成片视频：用封面/当前预览帧（静帧图片）在库里新建一条主体（主图=该静帧，不是整段视频）；库里有、画布不多节点。
  • 「保存到主体库」菜单仅出现在：图片节点；有成片的视频节点；主体节点（有主图才算保存成功，无主图 → 可点，Toast「请先添加主体图片」）。
  • 音频节点、文本节点：菜单不出现「保存到主体库」、也不出现「复制为图片」。原因：主体是「可反复 @ 的身份锚点」，本期定义必须有主参考图（音色只是主体上的可选附件）；纯音频/纯文本不能单独构成一条主体，故不提供「存进主体库」。文本可下载导出；音频可下载文件。
  • 空视频（无成片）：不出现「保存到主体库」；点下载 → Toast「无成片，无法下载」。
  • 空白画布右键：新建节点 ›（文本 / 图 / 视 / 音 / 主体）、粘贴、撤销、重做。
  • 本期菜单不出现「应用全部历史」。

页面交互

  • 右键打开菜单；点空白关闭。
  • 「新建节点 ›」悬停或点击展开子菜单，点类型后 addNode。
  • 无素材下载：优先可点 + Toast「无素材可下载」；若用禁用态，文案须可见为「下载（无素材）」，禁止无说明灰掉。

异常

  • 无剪贴板时粘贴禁用，文案含「无内容」。
  • 锁定节点：仍可右键打开菜单并「解锁」。
  • 生成中删除（已定）：菜单「删除」保持可点；点击后不删除，Toast「生成中，暂时无法删除」。生成结束后可正常删除。本期不做「二次确认后仍可删」。

数据流转

菜单操作直接改节点/剪贴板/画布集合；保存到主体库写入账号主体库。

P1-4 主体节点

功能逻辑

主体节点是干什么的（大白话）

用来记住「这个角色/物体长什么样」，好让后面多次生成图、视频、音频时，用 @主体名 把它挂上去，尽量保持同一个人/同一个物。它不是又一张图片结果卡，也不是写文案的文本卡；主体卡自己一般也不再跑一轮「文生图主流程」——主业是被别的生成节点引用。

图片节点主体节点
主要存什么一张画面（素材或生成结果）一套「身份」：名字 + 可选描述 + 主参考图 + 最多 3 张辅图 + 可选音色
怎么用当结果看、当素材下、也可被 @主要给图/视/音生成 @，保证多次生成长得像
和「库」的关系一般不进主体库可「保存到主体库」（账号下），别的画布还能「导入主体」再用

业务规则

1. 空卡长什么样

  • 左侧栏点「主体」→ 画布落下空主体卡。
  • 空态固定文案（已定）：「定义一个可反复引用的角色/物体身份；在图片、视频、音频生成里用 @ 调用。」
  • 空态四个入口（都要有）：「导入主体」「从画布选择」「从资产库选择」「本地添加」。

2. 卡上有哪些字段（填满后）

  • 名称：显示成 @名称，可改名；下游 @ 菜单里用这个名字。
  • 描述：可选短说明（给模型看「这是谁」）。
  • 主图（已定：只能是图片）：必须有 1 张图片，才算「可用主体」。可替换、可移除。不能把视频文件本身放进主图槽。
  • 辅图（已定：只能是图片）：最多 3 张图片，可选。用来补充角度/服装等参考。不能放视频。
  • 和「视频保存到主体库」怎么对上：有成片的视频节点右键「保存到主体库」时，系统用该视频的封面图 / 当前预览帧（一张静帧图片）去新建一条主体（主图=这张静帧），不是把整段视频当成主体主图存进去。画布上同样不会自动多出一个主体节点。
  • 音色：可选。绑一条音频（本地 / 资产库；智能配音若后台有能力再开）。只能从系统内置音色列表里选一条，不能本地上传、也不能从资产库挑音频文件。点「选择音色」打开列表，点一项即绑定；可清除。没有音色不影响「有主图就能被 @」。

3. 四个入口分别干什么

  • 导入主体：打开账号主体库，选一条已有主体 → 填进当前这张卡（不是再新建一张空卡）。库是空的就提示没有可用主体。
  • 从画布选择：只能点选画布上有画面的图片节点（或其它节点里可选的图片结果），写入主图或辅图；点到视频节点 → Toast「主体主图/辅图仅支持图片，请选择图片或先用视频「保存到主体库」」。
  • 从资产库选择：从普通素材资产库选图片，写进主图或辅图；视频素材不可选入主/辅图槽。
  • 本地添加：仅允许上传图片；选视频文件 → Toast「仅支持添加图片」。

4. 「主体库」和画布节点别混

  • 主体库 = 挂在当前账号下的主体资产列表（跨画布可复用）。不是项目共享库。
  • 右键「保存到主体库」= 把当前卡（须已有主图）存进库；Toast「已保存到主体库」；画布不会因此再多出一个主体节点。
  • 要用库里的主体：走空卡/卡上的「导入主体」，才会填到画布这张卡上。

5. 谁可以 @ 这张主体

  • 可以：图片生成、视频生成、音频生成（见 P0-4 矩阵）。
  • 不可以：文本节点生成（见 P1-3）；文本侧点主体 → Toast「文本节点不能引用主体」。
  • 还没有主图时：别人 @ 列表里仍可看到并点，但 Toast「请先添加主体图片」，不建立引用、不连线（可点 + Toast，不静默灰掉）。

6. 下载

  • 有主图：可下载主图。
  • 无主图：下载保持可点，Toast「请先添加主体图片」，不下载。

页面交互

  • 点主图槽 / 辅图「+」→ 出来源（与产品一致：本地 / 资产库 / 画布等）→ 写入对应槽。
  • 点音色「上传/更换」→ 选音频绑定或更换；可清除。点「选择音色」→ 系统音色列表（示意：温柔女声 / 磁性男声 / 童声）→ 点一项绑定到本卡；列表里没有「本地上传」。再次打开可换一条；「清除」去掉音色。
  • 改名称、描述：点字段直接编辑。
  • 清除：支持清主图、清辅图；清主图后卡回到「无主图」态（下游 @ 走第 5 条提示）。
  • 右键：含「保存到主体库」等（见 P1-1）；无主图保存 → Toast「请先添加主体图片」。

异常

  • 主体库为空：导入面板空态「没有可用主体」+ 引导去保存或新建。
  • 导入/上传失败：Toast 说明原因；卡上数据不变。
  • 辅图已满 3 张再添加：Toast「最多添加 3 张辅图」；不覆盖已有（除非用户先删再加）。
  • 无主图被 @ / 下载 / 保存到库：均 Toast「请先添加主体图片」，零副作用。

数据流转

画布主体节点（名称、描述、主图、辅图、音色）↔ 可选同步到账号主体库（主体 ID）。图/视/音生成请求在用户 @ 后携带该主体 ID（及主图等参考），文本生成请求不带主体。

QM-2109

OPT-2 生成中状态

功能逻辑

接口无真实进度时，节点使用循环 loading，禁止假百分比进度。展示已等待时长与「通常约 x 分钟」。不允许取消。

业务规则

  • 主视觉：循环转圈/等效不确定动画；无百分比。
  • 文案：排队中（若有）→ 生成中。
  • 已等待 mm:ss + 旁注「通常约 x 分钟」（非进度条）。
  • 无取消按钮、无取消入口。
  • 失败：进入失败态，离开 loading；不单独做「重试」按钮，继续用节点旁原有的生成 / 发送入口。
  • 将来有真进度再上真进度环。

页面交互

  • 生成/超分开始出现蒙层；结束后消失并展示结果或失败。

异常

  • 断网：查询真实状态；不误判已成功。
  • 重复提交：生成中禁用再次发送。

数据流转

任务开始 → generating=true → 轮询/推送完成 → 写回结果或失败。

视频生成节点状态

挂在本块，不单开功能 ID。说的是「用来生成视频的视频节点」，不是本地拖进来的成片。本地素材没有下面这套生成状态。

基础状态

  • 待生成：还没有成片。节点是空画面，可写提示词并发送。没有「提示词已修改」条，也不能超分。
  • 生成中：蒙层 + 循环 loading + 已等待 +「通常约 x 分钟」。不能取消。引用到这个节点的小块悬停为「当前内容生成中」。这个节点的操作区在生成结束前不可点：不能播放、不能切换清晰度、不能下载、不能超分，生成框也不能输入或改引用。点这些位置没有效果，不另开一套提示。
  • 生成成功：展示成片，可播放、下载、超分。提示词与成片一致时不出现修改提醒。
  • 生成失败：离开 loading。失败出现在这个节点的画面区，文案「生成失败」，不在画布别处、也不单独做重试按钮。再用原来的生成 / 发送发一次。分两种，画面区都写「生成失败」：
    • 第一次、节点还是空的：画面仍空，空画面上显示「生成失败」。没有成片，也没有「提示词已修改」。
    • 节点里已经有上一版成片：成片留着，能看见，「生成失败」叠在这块画面上。若当前提示词已经和这块成片不一致，就同时保留「提示词已修改，请重新生成」。失败不会把旧成片清掉，也不会把「提示词已改」消掉。

独立状态

  • 已生成但提示词已改：成片还是上一次成功的结果，提示词已经和这次成片不一致。节点上出现提醒「提示词已修改，请重新生成」。成片仍可预览、下载；提醒只说明不一致，不自动重跑。再次生成成功后提醒消失，成片换成新结果。本块只定状态和文案，不改现有提醒条的样式。

各状态要单独看的交互

  • 生成中：必须有 loading，无百分比、无取消。
  • 已生成但提示词已改：必须有「提示词已修改，请重新生成」，成片保持旧结果。
  • 待生成、生成成功且提示词未改：按节点上原有播放 / 下载 / 超分即可，不另加状态条。
