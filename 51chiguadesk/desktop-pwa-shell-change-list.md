## 一、总原则（先对齐再改）

1. 结构尽量与 APP 对齐；桌面提高信息密度，避免把素材纵向拉高。
2. 详情整页沉浸：图文/社区偏左内容右信息；视频本期定 B 站式（左播放右简介/评论）。
3. 本版优先交互与 UI；完整业务能力后续补齐。上传 / 发布保留原有逻辑，不单独立项做 PC 专用优化。
4. 迭代节奏：APP 先改，PC 跟进；APP 有更新时同步桌面侧。
5. 广告沿用移动端，尺寸对齐 APP；宽屏用「一列多个」或「中间 + 两侧露出」控高。

### 发现页逻辑（CM-13）

入口与范围：

1. 社区顶栏子 Tab「发现」进入本页；与「推荐」互斥切换面板。
2. 「订阅」「关注」本期不改、不跟发现页结构。
3. 顶栏搜索、＋ 发布仍可用（发布无默认话题，同 CM-09）。

页面自上而下结构（对齐 APP 发现，桌面示意）：

1. **顶区三卡**：左大卡 + 右上下两小卡（如心愿墙 / 福利 / 成人运营位）。角标可标「社区发现页」。点击进对应运营位（落地接真实跳转；Demo Toast 占位）。
2. **筛选行**：文字 Tab，如热门大瓜 / 原创专区 / 今日吃瓜 / 兴趣癖好 / AI专区；选中态下划线强调色。切换后刷新下方话题与内容流（Demo Toast 占位）。
3. **横滑话题**：方卡封面 + 话题名 + 动态数；末项「更多话题」。点话题卡进入**同一套话题二级页**（CM-05～CM-08）；点「更多话题」进话题列表（Demo Toast）。
4. **内容流**：直接接在话题下方。样式先用 **APP 帖子流**，不用首页文章卡、也不用推荐流瀑布流卡。

内容流单条（APP 样式）包含：

- 头像、昵称、等级角标、日期、右侧「关注」
- 标题、正文摘要
- 三图宫格（可含视频 ▶、+N 更多图）
- 点整卡进帖子详情（CM-10）；点「关注」仅关注，不进详情

与推荐流差异（须写清）：

| 项 | 推荐 | 发现 |
| --- | --- | --- |
| 顶区 | 横滑 Banner + 公告 | 三卡运营位 |
| 筛选 | 最热/最新/视频/图片 + 布局切换 | 热门大瓜等文字 Tab，无布局切换 |
| 话题 | 竖卡横滑（在筛选上方） | 方卡横滑（在筛选下方） |
| 列表样式 | 默认瀑布流卡片，可切贴吧模式 | APP 帖子流（头像信息流）；不用首页卡 |
| 本期范围 | 改造 | 改造（本专节） |

## 九、广告与素材（跨页）

投放口径（已定）：

1. PC **沿用移动端广告**，不单独配位、不单独 SSP / 商务位。
2. 广告尺寸与 APP **尽量一致**；桌面禁止「单条拉满整宽 → 高度跟着暴涨」。
3. 宽屏排布二选一（或按位组合）：**一列多个**（并排 / 横滑多帧），或 **中间正常 + 两侧露出**。

## 十一、Demo 已示意 · 研发落地补齐

UI / 跳转 Demo 已齐；落地时接真实数据与能力（Toast / 假数据替换）：

1. **首页**：内容流、频道、顶栏 Banner、信息流广告、悬浮广告接投放与内容接口；榜单 / 签到 / 历史跳转现网 PC 同款二级页（非弹窗）。
2. **搜索**：热搜、历史、结果双 Tab（文章首页卡 / 帖子默认可切贴吧模式）、标签纯文章二级页接检索。
3. **视频**：三列列表、解锁角标（VIP / 金币）、B 站式详情（播放器底栏、看完整版、简介 / 评论、推荐）。
4. **社区 · 推荐**：Banner、话题横滑、筛选、卡片/贴吧切换、发帖弹层（遮罩不关）、帖子详情、右侧栏作者 / 官方。
5. **社区 · 发现**：三卡运营位、筛选、话题、APP 流内容；点话题进同一话题二级；订阅 / 关注本期不改。
6. **话题二级**：信息卡 + 发布带默认话题、筛选、卡片/贴吧流。
7. **福利**：双广告 + 保留分类的一排 6 大图标（加大铺满）。
8. **约炮**：栏目 / 包养 / 外围楼凤会所 / 认证专区、高级筛选、店铺详情与店员、更多店铺。
9. **广告**：沿用移动端素材与投放；按第九节排布接现网广告，控高不单条撑满。
10. **上传 / 发布**：沿用现有业务逻辑，本期不另做 PC 专用上传优化。
