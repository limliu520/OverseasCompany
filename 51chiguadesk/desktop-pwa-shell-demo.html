临时讨论 · 会议纪要

会议时间：2026-11-18 10:57–11:37（北京时间）。参与：曾阿牛、萧玖、曾世傲、晋瑞、小鹿等。桌面端 Flutter 独立开发（Win/Mac 同一套），数据沿用 APP；本页为讨论底稿，非正式产品 Tab。

会议结论 已对齐

  1. 整体方向
    结构尽量与 APP 对齐；内容提高密度、不做拉伸；详情整页沉浸并参考抖音/B 站/小红书；非核心页（我的、福利）沿用 APP 做大屏适配。本版优先交互与 UI，功能补齐后续再评估。
  2. 列表密度
    视频 2→3 列；社区 PC 用卡片并加到 4 列（APP 已从瀑布流改回广场式，PC 一并跟上）。首页倾向单列卡片（参考 Web 外端），宽度适当限宽。
  3. 详情形态
    图文/社区偏左图右文 + 底部推荐；视频可抖音式（点开评论弹层）或 B 站式（旁侧评论推荐），会上有倾向左内容右评论便于刷评论。
  4. 广告
    PC 与 APP 同素材时宽高尽量一致，避免 PC 把高度拉爆。倾向：广告区左右滑双帧，或中间广告 + 两侧露出以降视觉高度。PC 可单独配广告位（商务），顶部分类位 SSP 可单独给 PC，最好同步 APP 数据；关注放大模糊，建议分端素材。
  5. 迭代节奏
    APP 先迭代，PC 后续跟进；晋瑞在 APP 有更新时同步给曾阿牛。
  6. 用户定位补充
    会上提到 PC 更偏上传类用户，APP 偏普通用户——是否作为正式定位仍需产品确认。

视频 Tab（完全新增） 范围收口

  1. 1. 顶部搜索
    与首页同一套搜索逻辑与跳转（进搜索页）。
  2. 2. 分类 + 广告 + 平铺筛选
    分类频道行；其下广告位（可横滑）；再下方平铺筛选（最新 / 最热等）。
  3. 3. 视频列表
    三列卡片；左上角解锁角标 VIP 或「X 金币」。
  4. 4. 视频详情（B 站式 · 左视频右文）
    左：播放器 + 底栏（静音 / 时长 / 弹幕 / 清晰度 / 倍速 / 反馈）+「看完整版」（会员引导开通；金币够则扣币、不够引导买币）。右：简介 / 评论 Tab。简介 = 标题 + 浏览/点赞/评论/收藏/分享 + 标签 + 广告 + 推荐（上图下文一排 2）。评论 = 列表滚动、输入框固定底部。详情页隐藏右侧「联系我们 / 24H热瓜」。无抖音模式。

本期视频 Tab 范围以上 4 块；其余能力不扩。

约炮顶栏 / 栏目 已记

  • 顶栏右侧按钮
    保留「申请入驻」与「＋ 发布」；发布为主按钮（黑/强调底），申请入驻为描边次要钮。
  • 栏目 Tab
    推荐 / 包养 / 外围 / 楼凤 / 会所 / 认证专区。删除「同城速约」「高端定制」。认证专区与会所同交互，但不展示顶部横滑竖卡（直接筛选 + 列表）。
  • 右侧栏
    视频整页、约炮整页（含店铺详情 / 更多店铺）、福利页不展示右侧「联系我们 / 24H热瓜」。
  • 我的
    桌面 Demo 隐藏「我的」页；侧栏点「我的」不跳转，Toast「我的（请使用 APP 查看）」，沿用现有 Toast 样式。
  • 福利图标
    一排 6 个，图标加大。
  • 包养
    独立面板：顶栏筛选（猜你喜欢 / 最新上架 / 随机推荐 / 筛选）+ 左图右文三列卡片列表（城市 / 年龄 / 身高 / 胸围 / 最低消费）。
  • 外围 / 楼凤 / 会所
    统一 APP 交互：上横滑竖卡 → 筛选行（猜你喜欢 / 最新上架 / 随机推荐 / 筛选）→ 一排 4 卡片列表。筛选打开「高级筛选」弹层（年龄单选 + 服务类型多选；重置 / 确定；点遮罩不关）。
  • 店铺详情
    参考 APP：上部左图右文（店名 / 官方严选 / 城市 / 店内女郎数 / 简介）；中部综合 / 最新上架 / 价格优先 + 全部分类弹出；下部一排 4 店员卡（封面角标 + 标题 + 价格 + 服务标签）。

社区布局切换 已记 · 仅口径

  • 筛选栏右侧「布局」按钮
    逻辑口径：默认「卡片模式」（新增，当前 Demo 展示态）；可切回「贴吧 / 原有帖子模式」。Demo 不实现真实切换，点击仅 Toast「切换原有帖子模式」。
  • 帖子详情页
    沿用现有小红书式左右分栏，本期不改。

首页相关需求清单 进行中

  1. 1. 广告位置与交互
    顶栏 Banner：中间主位 + 两侧露出重叠，固定 823×413，可点两侧切换；信息流穿插广告：纯图、与文字卡同尺寸 823×303；搜索页广告：一排约 2–3 个横滑。右侧栏（联系我们 / 24H热瓜）保留现网 PC。
  2. 2. 内容卡片样式
    整图封面 823×303；底栏标题 + 作者/日期/分类小字；操作区右对齐（浏览 / 评论 / 点赞 + 分享）；列表最大宽 823、最小边距 24，比例固定等比缩放。
  3. 3. 榜单、签到入口与页面
    入口位置/样式按 PC 调整；榜单、签到均为独立二级页（不走弹窗），沿用现有业务逻辑。Demo 现状仍为弹窗，需改回独立页。
  4. 4. 新增悬浮广告位
    首页右下角竖版悬浮广告：可轮播、可关闭。
  5. 5. 搜索页 · 热搜总榜
    总榜样式优化，对齐 APP（桌面可 2–3 列）。
  6. 6. 搜索结果页 + 社区卡片
    搜索结果卡片样式调整；社区卡片同步调整到统一规范。
  7. 7. 搜索 · 标签与卡片
    热门标签保留；相关卡片样式按统一内容卡规范调整。
  8. 8. 历史页卡片统一
    历史记录等页的卡片也改成统一内容卡片规范（同首页文字卡）。

待跟进 待拍板/待沟通

    与 APP 同构即可，还是另有额外目标背景（上传效率、投放、时长等）？影响列表/详情/迭代取舍。
  • 广告最终形态与技术实现
    双帧横滑 vs 中间露出两侧；与研发确认素材比例、SSP/商务单独配置流程；PC 与 PWA 同素材时宽高对齐。
  • 视频详情主推范式
    抖音式弹层评论 vs B 站式侧栏评论推荐，是否按内容类型分流。
  • 发布与上传流程
    后续是否需要针对上传类用户优化 PC 发布/上传流程。
  • 福利页铺法
    萧玖：不要细分推荐分类，直接全部铺出，避免显得空——待落地确认。
