# AI短剧 App 功能结构

从产品规划的前台结构和分阶段模块整理。本文只写 App 里用户能操作的功能。

运营侧的审核、上下架、推荐配置、用户管理、结算，不做成后台页面。用户只看到结果：审核中、已发布、驳回原因、首页推荐、收益数字。

## 前台结构

底栏五个入口。打开即为已登录。

```
App
├── 首页        剧情短视频、短剧片段、推荐、关注
├── 剧场        分类、热门、连载、完结、AI 短剧
├── 创作        上传、AI 图片、AI 视频、创作记录、短剧项目
├── 追剧        继续观看、收藏、更新提醒
└── 我的        个人作品、创作者中心、积分、订单、账号
```

首页只负责看。创作从「创作」进入，不挡看剧。

业务怎么落在这些入口上：

| 业务 | 用户在 App 里做什么 | 主要入口 |
|---|---|---|
| 短剧 | 选集、连播、收藏、续看 | 剧场、播放、追剧 |
| 短视频与 UGC | 看片段和投稿；片段挂到全集 | 首页、发布 |
| AI 创作 | 生成角色、场景、封面和剧情片段 | 创作 |
| AI 短剧 | 按剧目和分集管理，也允许外部成片上传 | 创作、建剧 |
| 创作者 | 主页、作品、更新；之后看数据和收益 | 我的、作者主页 |

三条流程：

- 观看：发现片段或短剧 → 看全集 → 收藏追剧 → 更新后再来
- 创作：选工具 → 生成 → 预览保存 → 提交审核 → 通过后可被观看
- 经营：发布 → 获得观看和互动 → 看表现 → 继续更新

## 一期

目标：能看、能生成、能发布、能看到审核结果、通过后能被别人看到。

| 模块 | 功能 |
|---|---|
| 账号 | 头像、昵称、简介 |
| 内容发现 | 首页推荐流、关注流；剧场列表；题材、热门、连载、完结、AI 短剧 |
| 短剧观看 | 简介、选集、播放暂停、拖动进度、上一集下一集、自动连播 |
| 片段进全集 | 首页片段进入对应剧的对应集 |
| 追剧 | 收藏、观看历史、从断点继续看 |
| AI 图片 | 输入描述、选基础参数、预览、保存 |
| AI 视频 | 图生视频、预览、保存 |
| AI 任务 | 生成中、成功、失败、历史、重新生成 |
| 作品发布 | 本地上传或选用生成结果；填标题、封面、分类；提交后进入审核中 |
| 短剧发布 | 建剧目、加分集、设集序、标连载或完结；短视频可关联某剧某一集 |
| 创作者主页 | 简介、作品列表、短剧列表、关注 |
| 基础互动 | 点赞、关注、举报 |
| 我的作品 | 草稿、审核中、已发布、驳回原因、修改后重提 |
| 积分 | 当前额度、生成前展示消耗、消耗记录、失败退回 |

一期要串起来的结果：

- 生成结果可以直接去发布
- 已通过的作品能在剧场和作者主页被看到
- 片段能进全集
- 从作品能进作者主页，从主页能进该作者的短剧

一期不做：复杂推荐、评论、搜索、榜单、文生视频、模板、素材库、付费墙、分成、剧本、分镜、在线剪辑、番外、多人协作。

## 二期

目标：观众会回来追，创作者会接着更新。

| 方向 | 功能 | 挂在哪个入口 |
|---|---|---|
| 追剧体验 | 连载更新提醒、预约、站内消息、追剧列表按更新查看 | 追剧、消息、播放页 |
| 内容发现 | 搜索、筛选、榜单、播放页相关推荐 | 剧场、播放页 |
| 社区互动 | 评论、回复、互动通知；用户可删自己的评论 | 播放页、消息 |
| AI 创作 | 文生视频、提示词辅助、时长和比例等参数 | 创作 |
| 轻量模板 | 从剧情片段套模板，改角色或场景，生成后发布，保留模板来源 | 播放页、创作 |
| 素材管理 | 角色参考图、场景图放进一部剧，下一集复用 | 创作 |
| 创作者中心 | 作品数据、分集数据、更新管理、认证标识（只展示） | 我的 |
| 创作者运营 | App 内看到邀约、活动、扶持额度到账 | 消息、活动、积分 |
| 商业化 | 购买创作套餐；精品集付费解锁；作者看到收益数字 | 我的、播放页 |

看剧权益和创作额度分开。套餐只增加创作积分。

## 三期

目标：一部剧可以连续做下去，创作者能长期经营。

| 方向 | 功能 | 挂在哪个入口 |
|---|---|---|
| 剧本辅助 | 大纲、分集剧情、对白，可改可保存 | 短剧项目 |
| 分镜制作 | 拆镜头、写描述、单镜头生成、替换某一镜 | 短剧项目 |
| 角色管理 | 角色设定、多张参考、跨集复用 | 短剧项目 |
| 成片制作 | 镜头排序、拼接、配音、字幕、导出 | 短剧项目 |
| 授权衍生 | 番外或另一结局，标明原作，不进正片选集 | 短剧项目 |
| 多人协作 | 项目成员、任务分工、版本记录 | 短剧项目 |
| 创作者经营 | 收益分析、合作与激励说明 | 我的 |

推荐仍只体现在首页和剧场的结果上。

## 四期

没有新的 App 页面。按观看、发布、留存和收入决定加供给、收入口，或停止扩展。
