版本目的 / 需求背景

主链路（登录、项目、账号、采集、素材、文章二次编辑）已可演示。独立子模块（如 AI 评论）本轮不动。本轮补齐「重构增值能力」，用于对外讲清：便捷、流程化、清晰。

要解决：日常处理少跳转；异常与流程态可见；问题可问可反馈；入驻与菜单可发现。登录页左封面商业化视觉后置，不进本版验收。

业务对象：主账号与子账号（Demo 在登录页选角色）。预期：同一套工作台与引导壳，内容随项目数据与权限变化。

WB · 工作台

功能逻辑

所有角色进入同一工作台页面。可见内容 = 当前会话权限 ∩ 可见项目/资产数据。不提供「主账号壳 / 运营壳」两套 UI。

页面由四个独立模块纵向排列：待办、提醒、工单跟进、快捷区。空模块在零数据时可保留空态句，不把不同类型条目塞进同一列表。

业务规则

  • 待办只放需要人执行的动作；内部分组为「入驻类」「业务类」。
  • 提醒模块内部分组为「流程提醒」「状态 / 异常提醒」；与待办不得混排。
  • 创建第一个项目：主 CTA 放在入驻类待办；流程提醒可并列一条进度说明，但不得替代待办主按钮。
  • 无对应权限的条目不展示（不做灰显一堆）。
  • 工单来自快速反馈；状态仅「待处理」「已处理」两态（Demo）。
  • 快捷区展示最近业务项目（最多 4 个）及「全部项目」；无项目列表权限则隐藏项目类快捷。

页面交互

  • 每条待办 / 提醒：标题、一句说明、主按钮或链接；点击跳转有权限的目标页。
  • 工单行：展示摘要、状态标签；待处理可点「模拟已处理」（仅 Demo）。
  • 零业务项目且已关欢迎弹窗：待办含「创建第一个项目」；项目管理页与工作台快捷区旁展示大引导卡「创建你的第一个项目」。

异常

  • 深链目标无权限：不生成该条目；若历史书签进入无权限页，Toast「当前角色无权访问」并回工作台。
  • 工单列表为空：模块内文案「暂无反馈工单」。

数据流转

待办 / 提醒由 Demo 本地 store 中项目状态、种子异常、素材/文章示意计数推导。工单写入 store.tickets，帮助中心提交时追加。

HF · 帮助与反馈

功能逻辑

全局右下角浮标打开帮助中心。默认首屏为常见问题列表与底部对话输入。快速反馈是帮助中心内的二级入口，点击后进入反馈表单，不是与 FAQ 并列的一级 Tab。

业务规则

  • FAQ 点击填入对话并给出固定答复；可附「去某某页」链接（按权限过滤）。
  • 对话答不出时，回复引导用户点「快速反馈」。
  • 反馈：必填说明；可选「附带当前页示意截图」（Demo 用占位图/标记，不真截屏引擎）。
  • 提交成功：Toast「已提交反馈」；关闭反馈子页回到帮助首屏；工作台工单块新增待处理。

页面交互

  • 浮标文案「帮助」；打开面板，遮罩点击或 Esc 关闭。
  • 首屏顶右有文字按钮「快速反馈」进入二级。
  • 反馈页顶左「返回帮助」。

异常

  • 说明为空点提交：Toast「请填写反馈内容」，不关闭。
  • 重复连点提交：一次成功即可，按钮提交中短暂禁用。

数据流转

FAQ 为前端种子。正式环境问答由 Admin 入库供检索——本 Demo 不接 Admin。反馈写入本地 tickets，口径对应 Admin 反馈列表。

LG · 引导

功能逻辑

两段引导互不替代：① 零项目欢迎弹窗只解决「有没有项目」；② 名下首次具备业务项目后，触发侧栏菜单逐步引导（到二级），按当前可见菜单裁剪步骤。

业务规则

  • 欢迎弹窗：仅零业务项目且未关闭过时出现；主按钮「去创建项目」进创建流；「稍后」关闭并记 dismissed。
  • 菜单引导：步骤 = 当前角色可见的一级下各二级入口；文案说明该入口用途；「下一步」/「跳过」；完成或跳过写入 menuTourDone（按账号维度）。
  • 主账号新建首个业务项目成功后，若尚未做过菜单引导，进入工作台时启动引导。
  • 子账号首次登录（该子账号 menuTourDone 为假）且可见至少一个二级菜单时，进入后启动引导。

页面交互

  • 引导层高亮对应侧栏二级项，气泡说明 + 下一步 / 跳过。
  • 最后一步主按钮为「完成」。

异常

  • 可见二级菜单为 0：不启动菜单引导。
  • 引导中用户点击其他导航：允许离开，当前步保留；再次回工作台不自动重开（除非未完成且本次会话仍标记 pending——Demo 定为：跳转则视为中断，下次进工作台若未 done 再提示一次「继续菜单引导」条，不强制遮罩）。

数据流转

zeroPromptDismissed、menuTourDoneByAccount 存 store。角色切换在登录页完成，不在壳内切换。

AU · 登录页演示角色

功能逻辑

退出登录回登录页。用户选择演示角色后进入（主账号日常 / 主账号新号零项目 / 子账号若干）。新号模式清空业务项目演示态并重置欢迎弹窗标记。

业务规则

  • 主账号日常：保留种子业务项目，便于讲工作台满态。
  • 主账号新号：业务项目列表为空，触发欢迎弹窗与零项目工作台。
  • 子账号：带入该子账号 features 与 displayName；侧栏按权限过滤。

页面交互

  • 登录页展示角色卡片列表；点选后「进入」；仍保留简易账号密码区可默认填演示值。

异常

  • 未选角色点进入：Toast「请选择演示角色」。

数据流转

会话字段：accountKind、accountId、displayName、features。侧栏与工作台只读会话权限。
