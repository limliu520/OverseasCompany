## 双联项目创建路线（已落地）

1. **新建向导**（`project-setup`）：填不依赖对接的配置（基础 / Userbot / 外站可挂待激活 / 水印·模板占位）→ 点创建  
2. **对接激活页**（`project-connect`）：展示凭证与 Token 接入方案、状态「待激活」；可点「测试激活」，也可「稍后」关掉  
3. **关闭后入口**：工作台待办「去激活」；项目管理列表「待激活 → 去激活」回到同一对接页  
4. **测试通过** → **激活后配置**（`project-after`）：自动流等 →「确认，完成创建」→ `ready`  
5. **任意状态可编辑**（`project-edit`）：基本信息 / 技术对接材料 / 自动流与通知；列表主入口是「编辑」，待激活另有「去激活」

状态：`pending_activate` → `need_post_config` → `ready`（可选演示 `need_collect`）

外站通道可在新建时建为待激活并挂项目；催办在待办，不挡建项。

## 交互规范（Demo 约定）

1. **强提醒**：欢迎类用弹窗一次；持续事项进工作台「今日待办」，不用顶栏大横幅。  
2. **零项目**：允许稍后，可空工作台浏览；从「项目管理 → 新建项目」再加。  
3. **侧栏**：各业务一级都展开二级；未做项点按「模块名 · 设计中」。  
4. **低频操作**：新建项目不放侧栏顶主按钮。  
5. **个人操作**：退出 / 改密等放左下角头像菜单。  
6. **命名**：账号资产与授权类入口统称「全局配置」，不叫「账号管理」。
