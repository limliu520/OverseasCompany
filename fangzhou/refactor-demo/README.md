## 已定产品口径（Demo 对齐）

1. **一个项目 = 一套内容通道**（方舟规范 / OASH 对接）；不做多 CMS 账号分发，**不配对方登录发布账号**。推送时带上子账号 CMS 标识，由接收方判断归属；业务方自行发布/二次编辑。  
2. **站点类型三选一**：瓜站（内容站）/ 视频站 / 短剧站。字段并集 = CMS 项目 ∪ 现网外站「**推送站点**」（见 `js/project-union.js`）；「拉取加水印」不进本 Demo。短剧站不配文章模板。  
3. **跑马灯、前台地址**彻底删除（不是待定）。  
4. **产品债务**：AI 评论功能后续**必须补「评论预览」**（前台地址预览入口已删，否则能力不完整）。侧栏「AI 评论」仍为 stub 时 Toast 会提示本条。  

## 列表翻页（强制约定）

凡表格 / 卡片列表（网站采集记录、素材、项目、子账号/岗位等）统一用 `js/pager.js`：

- 布局：左「每页显示」下拉，右「共 N 条」+ 页码（对齐现网）
- 可选条数：**20 / 30**，默认 20
- 换筛选 / 换 Tab / 换站点 → 页码回到 1
- 新增列表页必须带翻页，禁止只渲全量

## 采集菜单（阶段③骨架 · 2026-10-27）

侧栏「采集」仅三项（工作流监控 / 去水印预处理 / 独立审核与异常入口 **不做**）：

1. **TG 采集**：顶栏「项目切换」= **公共池 | 业务项目**（同级）。左号右详情：连接/拉取/挂频道/监听；公共池另有 TG→TG 路由。项目详情「TG 采集号」只展示 + 入口；项目管理列表不含公共池  

2. **网站采集**：上配置卡片 + 下记录表；绑同类型项目（瓜/视频/短剧均可，≤5，承接原外站）；状态机与启停开关分开；页面唯一 / 最多 50 链；记录含日期筛选、待采集、停止确认、进行中轮询、无编号态；翻页 20/30  
 
3. **素材管理**：同一张 materials、顶栏**三视图**（全部素材 / 垃圾素材 / 待我审核）。归属只分**公共池 | 业务项目**（无专属/外站）。公共池=未进项目的料（TG 未占用 + **网站未绑任何项目**）；分发频道仅 TG→TG；网站公共池无 TG 频道。分发项目=项目自采或转编辑占用（转编辑后离开公共池列表）。垃圾非状态筛。各视图筛选与表头独立；刷新≠重置；带翻页 

## 项目详情 Tab（`project-edit`）

水印管理 → … → TG 采集号（**卡片展示**；频道只读；操作去「采集 → TG 采集」）→ 推送规则 → 可选功能  



对接 / 生成 / 媒体 / 自动推送面板由 `FZProjectUnion.render*` + `collect*` + 校验驱动。

## 双联项目主路径（已落地）

1. **配齐**（`project-setup`）：基本信息、采集号、封面/水印、文章模板、自动推送意向等（创建流仍在收敛中）→ 创建  
2. **开发对接**（`project-connect`）：通道凭证与对接摘要只读；运营可关闭离开。通道**接通**后前置配置自动生效，**不必再回来配一轮**  
3. 「模拟接通」仅 Demo；正式环境可能由系统探测 / 业务方首次合法调用等自动变已接通  

状态：`pending_activate`（待接通）→ `ready`（完成）；可选 `need_collect`（已接通但开了自动推送仍缺采集源演示）

旧「激活后配置」页已改为跳转项目编辑。独立外站资产挂载已从项目详情去掉。

## 框架 / 信息架构约定（先定壳，再填模块）

1. **侧栏只放工作区入口**，不放「新建 xxx」等页内动作（新建在列表右上角）。  
2. **从属能力进页内 Tab**，不单独占二级（例：岗位 ∈ 子账号与授权）。  
3. 一级可有二级列表；未做模块 stub → Toast「设计中」（AI 评论另附评论预览债务说明）。  
4. 强提醒弹窗一次；持续事项进工作台待办。  
5. 零项目允许稍后。  
6. 退出 / 改密等放左下角头像菜单。  
7. 账号资产入口统称「全局配置」。  
8. 侧栏 `position: fixed`，避免整页跳转时菜单被顶走。  
9. **按钮必有反馈**：不可用置灰并可点出原因 Toast；校验失败 Toast（err）；成功 Toast（ok）或仪式感弹窗（创建成功说明阻塞项 + 主 CTA）。可选步未填时「下一步」不可用，只能「跳过」。
