## 双联项目主路径（已落地）

1. **配齐**（`project-setup`）：基本信息、Userbot、外站、水印位、**自动流意向 / Webhook** 等一次配完 → 创建  
2. **开发对接**（`project-connect`）：凭证与文档；运营可关闭离开。通道**接通**后前置配置自动生效，**不必再回来配一轮**  
3. 「模拟接通」仅 Demo；正式环境可能由系统探测 / 业务方首次合法调用等自动变已接通  

状态：`pending_activate`（待接通）→ `ready`（完成）；可选 `need_collect`（已接通但开了自动流仍缺采集源演示）

外站可待激活挂项目；催办在待办。旧「激活后配置」页已改为跳转项目编辑。

## 框架 / 信息架构约定（先定壳，再填模块）

1. **侧栏只放工作区入口**，不放「新建 xxx」等页内动作（新建在列表右上角）。  
2. **从属能力进页内 Tab**，不单独占二级（例：岗位 ∈ 子账号与授权）。  
3. 一级可有二级列表；未做模块 stub → Toast「设计中」。  
4. 强提醒弹窗一次；持续事项进工作台待办。  
5. 零项目允许稍后。  
6. 退出 / 改密等放左下角头像菜单。  
7. 账号资产入口统称「全局配置」。  
8. 侧栏 `position: fixed`，避免整页跳转时菜单被顶走。  
9. **按钮必有反馈**：不可用置灰并可点出原因 Toast；校验失败 Toast（err）；成功 Toast（ok）或仪式感弹窗（创建成功说明阻塞项 + 主 CTA）。可选步未填时「下一步」不可用，只能「跳过」。
