# 方舟重构 Demo · DESIGN.md

运营后台视觉说明书。Agent 改 UI 时优先读本文件；不要套营销站深色大字报。

## 1. 气质

- 浅色精密 B 端：干净、密而不乱、层级清楚。
- 参考：Linear / Notion 产品壳（浅色），不是落地页。
- 中文运营场景：列表 + 筛选 + 侧栏为主；少装饰、少嵌套卡片。

## 2. 色板（语义）

| Token | 用途 |
| --- | --- |
| `--bg` | 画布浅灰 |
| `--paper` | 卡片/表纸白 |
| `--sidebar` | 侧栏略深于画布 |
| `--ink` | 主文字（略暖黑，非纯黑） |
| `--muted` | 次要说明 |
| `--line` / `--line-strong` | 分割与描边 |
| `--accent` | 主行动（靛紫，克制） |
| `--ok` / `--warn` / `--danger` | 状态语义 |

禁止：大面积紫渐变、灰字压在彩底、卡片套卡片。

## 3. 字体

- 中文优先：PingFang SC / Noto Sans SC
- 标题克制加粗，列表正文 13–14px，辅助 12px
- 等宽仅用于 ID / 时间 / 代号

## 4. 组件

- 按钮：主按钮实心 accent；次按钮白底描边；危险少用实心红
- 输入：浅描边、清晰 focus 环（accent 淡色）
- 表格：表头弱底、行 hover 极淡、操作列右对齐
- 侧栏：当前项浅底，勿大红标「已做」
- Badge：语义色浅底 + 深字

## 5. 布局

- 侧栏固定宽；主区 padding 均匀
- 工具栏一行优先；挤不下再换行
- 空态短句，不堆插画
