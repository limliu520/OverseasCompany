需求背景

运营在「项目管理 → 编辑项目」配置水印时，现网靠「有没有上传素材」暗示是否生效，缺少明确开关；视频水印缺少镜像翻转、间歇显隐、移动速度等防盗与观感调节能力；图片经水印服务输出时固定 PNG，需要可改 JPG。

另需在成片前后拼接完整片头、片尾视频。片头片尾不是叠层水印，作为编辑项目内、水印区下方的独立模块配置。因视频服务不支持横竖屏互转，片头、片尾须分别上传横屏与竖屏两套素材（启用两端时共四套）。

做：仅 CMS「编辑项目」弹窗；图片输出格式；各水印启用开关；视频水印镜像翻转与间歇展示；移动水印速度；片头片尾独立模块。

不做：外站站点水印；把片头片尾算作水印类型；浏览器以外的其它入口。

前提：水印 / 成片服务已支持本 PRD 描述的全部能力，方舟配置保存后按配置生效。

FZ-FMT-01

图片输出格式

功能逻辑

项目保存一套图片输出格式。水印服务按该格式输出封面等处理后的图片。与水印素材上传允许的文件类型无关。

业务规则

  • 选项：PNG、JPG。默认 PNG。
  • 位置：紧挨「图片封面尺寸」控件组。
  • 仅影响本项目后续新产出的图片；不回溯已生成历史文件。

页面交互

  • 下拉或单选切换 PNG / JPG；随「保存」一并提交。
  • 旁注说明：「水印服务封面等出图格式，不是水印素材上传格式」。

异常

  • 未选择：按 PNG。
  • 保存失败：Toast「保存失败，请重试」；界面值可保留用户选择，以服务端成功回写为准。

数据流转

字段随项目配置保存；转编辑 / 出图任务读取项目输出格式传给水印服务。

FZ-WM-01

水印启用开关

功能逻辑

每种水印（图片、固定、四角循环、移动）标题行提供开关。打开表示该类型配置启用并参与压片；关闭表示未启用，不参与压片。

业务规则

  • 每类型最多保留 1 套素材与参数；可多类型同时启用。
  • 关闭开关：下方配置区隐藏，不清除已上传素材、位置、宽度比例及翻转 / 间歇 / 速度等参数。
  • 启用但未上传素材：保存时 Toast「请先上传水印素材」，该类型不视为有效启用；其它已有效类型仍可保存。
  • 启用但未上传素材（含移除后）：整单项目不保存，Toast「请先上传 XXX水印素材」（XXX 为类型名，如移动水印）。须先上传或关掉该开关。不自动忽略该类型，也不自动把开关改回关闭。
  • 存量迁移（老数据无启用字段）：有对应素材 → 视为已启用；无素材 → 关闭。编辑回填与转编辑均按此规则，避免原有水印突然失效。
  • 日常编辑以开关为准；上传入口仅在开关打开后展示。
  • 交互通则：所有开关（含模块总开关、镜像翻转、间歇展示）均控制其下方内容是否展示；关闭则隐藏，打开再展示。

页面交互

  • 开关在标题行右侧；关闭时只保留标题行与开关，下方配置整块不展示。
  • 再次打开：展开配置，数值与素材仍是关闭前的状态。

异常

  • 全部水印关闭：允许保存；成片不叠本项目添加水印（去源水印若有其它链路逻辑不在本期改）。
  • 任一水印开关开着且无素材：整单不保存，见上 Toast。

数据流转

各类型增加 enabled 布尔；压片请求只带 enabled=true 且素材齐全的类型。存量无字段时按「有素材=开」推导。

FZ-WM-02

视频水印镜像翻转

功能逻辑

对固定 / 四角循环 / 移动水印，可开启水平整块镜像翻转（非整词换序）。开启后按配置间隔周期性在「正常朝向」与「水平镜像」之间切换。

业务规则

  • 仅视频三类水印；图片水印无此配置。
  • 与间歇展示相互独立，可同时开。
  • 字段：开关 +「每隔 N 秒翻转一次」。N 为正数，单位秒，默认 5；最小 1。
  • 翻转的是水印图层，不是整段成片画面。

页面交互

  • 「镜像翻转」使用开关，不用复选框。
  • 打开开关后展示间隔输入框；关闭则隐藏间隔输入，再次打开带回上次值。

异常

  • N 为空或 < 1：保存时 Toast「翻转间隔至少 1 秒」；不提交该非法值。

数据流转

随该水印类型配置写入；压片时交给水印服务按间隔镜像。

与 FZ-WM-02 共用截图 demo-wm-flip-intermittent.png。

FZ-WM-03

视频水印间歇展示

功能逻辑

开启后水印按「显示 X 秒 → 隐藏 Y 秒」循环，不再常驻画面。关闭后恢复常驻（现网默认观感）。

业务规则

  • 适用于固定 / 四角循环 / 移动。
  • 字段：开关 + 显示秒数 X + 隐藏秒数 Y。默认 X=3、Y=3；均须 ≥ 0.5。
  • 与镜像翻转独立。

页面交互

  • 「间歇展示」使用开关，不用复选框。
  • 打开后展示「显示（秒）」「隐藏（秒）」；关闭则隐藏这两项，再次打开带回上次值。

异常

  • X 或 Y 非法：Toast「显示/隐藏时长至少 0.5 秒」；不保存非法值。

数据流转

随类型配置保存并传给水印服务。

FZ-WM-04

移动水印速度

功能逻辑

为移动水印增加「一圈（一个来回）所需秒数」。数值越小运动越快，越大越慢。

业务规则

  • 仅「移动水印」展示。
  • 主字段为秒数；默认 10。
  • 主字段为秒数；默认空。上传移动水印素材后，按素材时长自动填入（例：水印视频 5 秒 → 填 5；PNG 可按旧逻辑默认 5）。运营可再改为 1～120。
  • 存量：一圈耗时留空则不传速度参数，水印服务继续旧逻辑（视频跟素材时长 / PNG 5 秒一圈）。不统一改成固定 10 秒。
  • 允许范围 1～120（有值时）；超出时 Toast「请输入 1～120 之间的秒数」。
  • Demo 可附「相对默认」只读提示（如当前为默认的 0.5x / 2x），不以倍率为主输入。

页面交互

  • 数字输入框，标签「一圈耗时（秒）」；说明「默认 10 秒；改成 5 更快，改成 20 更慢」。
  • 数字输入框，标签「一圈耗时（秒）」；说明「默认为空；上传素材后按素材时长填入；改小更快、改大更慢」。

异常

  • 空值保存：回退为 10。
  • 空值保存：允许，表示走服务端旧速度逻辑（存量兼容）。

数据流转

写入移动水印配置；有值时作为轨迹周期传给水印服务；空则不传该参数。

FZ-IO-01

片头片尾（独立模块）

功能逻辑

在编辑项目中、全部水印块下方，新增「片头片尾」模块。片头拼在正文视频之前，片尾拼在之后。只做拼接，不在片头片尾时段叠加本项目水印。

视频服务不支持把横屏片头/片尾自动变成竖屏（或反之）。运营须按成片方向分别上传到横屏 / 竖屏槽位。成片为横屏时用横屏套，为竖屏时用竖屏套。

业务规则

  • 上传位固定四个：片头横屏、片头竖屏、片尾横屏、片尾竖屏。
  • 只有一个模块总开关，没有「启用片头 / 启用片尾」独立开关。新项目默认关闭。
  • 片头、片尾仍可只配一端或都不配：不配片头则两个片头位都留空；不配片尾则两个片尾位都留空。
  • 一旦要启用片头：片头横屏与片头竖屏都必须已上传，缺一不可。片尾同理。
  • 不允许「只上传横屏、指望服务转成竖屏」；保存时若某一端只传了一向，Toast 说明缺哪一向。
  • 总开关开着：某一端只要上传了横屏或竖屏任一向，即视为该端已启用（不要求必须横竖都齐）。
  • 总开关开着：四个上传位至少要有一个素材才能保存；四空则整单不保存。
  • 总开关关着：四个文件可照常保存，但不拼接。
  • 上传时校验实际画面方向：宽 ≥ 高（含相等）→ 横屏；宽 < 高 → 竖屏。传到错误槽位拒绝写入。
  • 素材必须为视频（MP4 / MOV）；时长暂不设上限。单文件 ≤ 200MB（沿用视频水印）；生产 Cloudflare 实际常 ≤ 100MB，超限需压缩。
  • 不是水印类型；无位置、无宽度比例、无镜像 / 间歇 / 速度。
  • 模块总开关关闭时隐藏下方四个上传位（保留已上传文件）。

页面交互

  • 标题「片头片尾」+ 说明：须按槽位上传横屏 / 竖屏；服务不支持横竖互转；不是叠层水印。
  • 总开关关闭时只留标题行；打开后展示 2×2 上传区。
  • 每位：上传、预览、移除；已加载显示文件名。

异常

  • 上传非视频：Toast「请上传 MP4 或 MOV 视频」；不写入。
  • 上传失败：Toast「上传失败，请重试」。
  • 片头横屏或竖屏缺一（另一向已有）：Toast「片头需同时上传横屏和竖屏视频」，本次保存不生效。
  • 片尾横屏或竖屏缺一（另一向已有）：Toast「片尾需同时上传横屏和竖屏视频」，本次保存不生效。
  • 总开关开着且四个素材均为空：Toast「片头片尾已开启，请至少上传一个片头或片尾视频」，本次保存不生效。
  • 方向不符：Toast「这个位置需要横屏视频」或「这个位置需要竖屏视频」；不写入该文件。
  • 超过大小上限：按现网视频水印上传失败提示处理。

数据流转

四个文件地址随项目保存。成片时按正文视频方向选取对应朝向的片头/片尾再拼接；该方向无素材则该端该片不拼接。片头片尾内容本身不再走添加水印。
