一、需求目的

为不同推广平台、账号配置独立推广链接，统计品宣网从落地访问、下载页访问、点击下载到进入 51吃瓜网的转化，方便运营评估各渠道及账号引流质量。

5.3 指标口径

推广链接即固定落地页链接。落地访问同时展示 PV、UV；下载相关链路与转化一律按 UV（人数）统计，界面文案须带「UV」后缀，避免与 PV 混淆。

指标口径说明
PV次数落地页访问次数
UV人数落地页访问人数
下载页访问（UV）人数到达下载页的人数
下载点击（UV）人数在下载页点击下载的人数
51吃瓜网转化（UV）人数经该渠道从品宣网成功进入 51吃瓜网的人数

用户到达落地页后，路径全程保留渠道来源（推广码），便于后续下载页访问、点击下载及跳转 51吃瓜网的归因。

5.4 展示与导出

  • 汇总卡片 + 简单图表（示意）+ 明细表
  • 明细含：推广码 + 渠道名 + 代理名 + 指标；下载页访问 / 下载点击 / 51吃瓜网转化列名须标注 UV
  • 导出当前筛选下的明细（列名与界面一致，含 UV 标注）
