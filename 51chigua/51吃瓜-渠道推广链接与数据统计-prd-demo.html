51吃瓜品宣网 / 51吃瓜 APP · 渠道推广链接配置与数据统计

版本 v2.1 · 2026-10-23 · 一套后台管品宣网 + APP · 截图均来自本页 Demo（可点击放大）

一、需求目的

为不同推广平台、账号配置独立推广链接：品宣网侧重访问到跳转 51吃瓜网的转化；51吃瓜 APP 侧重下载、打开到注册、付费，方便运营评估各渠道引流质量。

二、范围

模块内容
菜单新开「渠道管理」→ 渠道配置、渠道统计
覆盖产品品宣网、51吃瓜 APP（同一套配置；统计按产品分 Tab）
渠道配置新建、启停、复制、有限编辑（仅名称/备注）；落地页固定，不配目标页
渠道统计 · 品宣网PV、UV、下载点击、51吃瓜网转化数；汇总 + 图表 + 明细 + 导出（无注册/充值）
渠道统计 · 51吃瓜 APPPV/UV、下载点击人数、首次打开、注册及转化率、首充及金额、付费及金额；汇总 + 明细 + 导出
筛选日期；渠道名/代理名搜索；推广码（展示带名称）
归因一律跟推广码；名称可改只影响展示

  • 渠道统计：内部分 Tab「品宣网」「51吃瓜 APP」，指标分表展示

五、渠道统计

5.1 页面示意（Demo）

5.2 筛选（两 Tab 共用）

  • 日期范围
  • 渠道名 / 代理名：搜索（可联想）
  • 推广码：主筛选；选项须带可读信息，如 n7hdmuw6｜品宣网｜Twitter｜Twitter01

产品维度用统计页顶部 Tab 切换，不再与「全部产品」混在一张指标表里。

5.3 指标口径说明

推广链接即固定落地页链接，链接点击与落地页访问视为同一口径，统一用 PV（访问次数）/ UV（访问人数），不再单列「链接点击次数/人数」。

品宣网

指标说明
PV / UV落地页访问次数 / 人数
下载点击下载/跳转相关按钮点击次数（访问→点击）
51吃瓜网转化数经该渠道从品宣网成功进入 51吃瓜网的转化量

品宣网不统计注册、充值。转化对比看「访问 → 下载点击 / 进入 51吃瓜网」。

51吃瓜 APP

指标说明
PV / UV落地页访问次数 / 人数（= 打开推广链接）
下载点击人数落地页下载按钮点击人数
首次打开人数安装后首次打开 APP 人数
新增注册 / 注册转化率注册人数；转化率 = 注册 / UV
首充人数 / 首充率 / 首充金额首充相关
付费人数 / 付费金额渠道用户付费汇总

APP 路径需尽可能保留渠道来源：打开推广链接 → 落地 → 下载 → 打开 APP → 注册 / 付费，均归因到推广码。

5.4 展示与导出

  • 汇总卡片 + 简单图表（示意）+ 明细表
  • 明细含：推广码 + 产品 + 渠道名 + 代理名 + 对应指标
  • 导出当前 Tab、当前筛选下的明细

六、验收标准

项标准
配置可为品宣网、51吃瓜 APP 分别建链；落地固定；可复制；名称/备注可改；码与地址不可改；无删除
统计分表品宣网 / APP 两个 Tab，指标各自独立
口径不重复统计「链接点击」与 PV/UV
筛选日期、名称搜索、推广码（带名称展示）
归因跟推广码；APP 下载打开后注册付费可关联
导出可导出当前明细
