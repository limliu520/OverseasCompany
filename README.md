# OverseasCompany

海外相关产品材料与交互 Demo 仓库。

## 正式需求（PRD）

- **交付形态：HTML PRD**（不以 Markdown 当研发终稿）。
- **Agent / 写作强制规范：** [`.cursor/rules/overseas-prd.mdc`](.cursor/rules/overseas-prd.mdc)  
  （结构、交互细节、异常、截图放大等；后续本仓库生成/修改需求文档均按此执行。）
- 截图放大细则： [`.cursor/rules/html-image-lightbox.mdc`](.cursor/rules/html-image-lightbox.mdc)
- 编辑源目录：`海外项目/`（主目录副本按 `.cursor/rules/haiwai-source-of-truth-sync.mdc` 同步）。
- `海外项目/需求规范.md` 为产品组制度**参考**，不替代上述 Agent PRD 规范。
